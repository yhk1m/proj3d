# 회전 중심 표시 · PNG 저장 모달 — 설계

날짜: 2026-09-28 · 대상: proj3d-astra (Projection 3D)

## 1. 회전 중심 표시 (e-GIS 3D 방식)

- 회전 중심(`controls.target`)에 작은 빨간 점(구, `0xff3b30`)을 항상 표시. `depthTest: false`, `renderOrder` 최상위라 가려지지 않음. 카메라와 중심 사이 거리에 비례해 크기를 바꿔 화면상 크기 일정.
- **더블클릭**(마우스) / **두 번 탭**(터치, 320 ms · 32 px 안)으로 중심 이동. 레이캐스트 대상은 지구본 메시와 종이 메시(보이는 것만). 빈 우주를 누르면 아무 일 없음.
- 이동은 즉시(애니메이션 없음). 카메라 위치는 그대로, 바라보는 점만 바뀜.
- 중심을 옮기면 `rig.autoFrame = false` (자동 맞춤이 중심을 도로 끌고 가지 않도록). 「시점 자동 맞춤」 버튼, 단계·도법 변경(`refresh`)은 기존대로 자동 맞춤을 켜 원래 중심으로 복귀.
- 왼쪽 위 시점 버튼(`#viewtools`: 맞춤 · + · −) 옆에 **「중심점 숨기기」** 체크박스. 상태는 localStorage `proj3d.hidePivot` (try/catch). 헤더는 한 줄 유지.
- 모듈: `js/scene/pivot.js` — `PivotMarker`(표시·크기 갱신·보이기) + `installPivotPicking(canvas, camera, targets, onPick)`.

## 2. PNG 저장 모달

### 진입
- 리모컨 유틸 줄(저사양 · 전체화면 · 링크 복사)에 **「PNG 저장」** 칩 버튼. 모바일은 햄버거 서랍의 같은 유틸 줄(`mountUtilControls` 두 인스턴스 공통).
- 누르면 모달: 제목 「PNG 저장」, 미리보기(체크 상태를 바꾸면 즉시 갱신, 투명 부분은 체커보드 배경으로 표시), 체크박스 ☑ 채우기 · ☐ 색 반전 · ☑ 경위선, 버튼 [취소] [저장]. Esc · 바깥 클릭 · 취소로 닫힘. 체크 상태는 localStorage 에 기억.
- 모달은 기존 `.popover` 톤(남색 패널·`--accent` 제목)을 따르는 새 `.modal` + 반투명 뒤판. UI 이모지 금지, 아이콘은 선 SVG.

### 그리는 내용
- **지금 종이에 그려진 모양**을 정면 2D 로: `state.frame()` 의 `f`(투영), `domain`, `rotation`(정축·횡축·사축). 조정 애니메이션 중간이면 그 순간 모양. 카메라 각도와 무관.
- 요소: 지도 테두리(도메인 외곽선), 바다 면(테두리 안), 땅 면(land-110m 폴리곤), 해안선, 경위선(15°, 체크 시).
- 크기: 지도 bbox 의 긴 변 3000 px + 사방 여백 1 %. 지도 밖은 투명(알파 0).
- 파일 이름: `{도법 이름}.png` (예: `Equal Earth 도법.png`). `canvas.toBlob` → 다운로드 링크.

### 색 규칙 (두 색만: #000000 · #ffffff)

| | 바다(지도 안) | 땅 | 선(테두리·해안선·경위선) |
|---|---|---|---|
| 기본 | #ffffff | #000000 | #000000 |
| 색 반전 | #000000 | #ffffff | #ffffff |
| 채우기 끔 | 투명 | 투명 | #000000 (반전 시 #ffffff) |

- 채우기가 켜져 있으면 그리는 순서: 바다 → 경위선 → 땅 → 테두리. 경위선은 땅 아래라 바다 위에만 보임.
- 채우기가 꺼져 있으면: 경위선 → 해안선 → 테두리 (선만).
- 선 굵기: 테두리 3 px, 해안선 2 px, 경위선 1.5 px (3000 px 기준). 안티앨리어싱 가장자리의 중간색은 허용(면 자체는 순색).
- 색 반전은 PNG 전용. 화면 지도 색은 바꾸지 않음.

### 벡터 경로 생성 — `js/export/mapVector.js` (순수 함수, DOM 없음)
`buildMapVector(frame, land, { graticule })` → `{ bbox, sea: Path[], land: Path[], coast: Line[], graticule: Line[], outline: Line[] }` (종이 좌표 [x, y]).
- 모든 지리 자료는 (λ, φ) 로 보관 → `rotation.forward` 로 프레임 좌표 (λ′, φ′) → 잘라내기 → 간격 ≤ 1° 로 촘촘히 → `f` 로 투영 (기존 `B_t(f(R))` 규칙과 같은 순서).
- 잘라내기:
  - 날짜변경선(λ′ = ±180°): 폴리곤은 d3 `geoClipAntimeridian` 의 polygon 스트림, 선은 기존 `splitLines`.
  - 사각 도메인(`phiMin/phiMax`, 경도 범위): (λ′, φ′) 평면에서 사각형 클리핑.
  - 구드 절개선(`domain.cuts`): 로브별 사각형(경도 구간 × 반구)으로 폴리곤을 클리핑하고, 선은 기존 `splitAtCuts`.
  - 원형 도메인(`kind: 'cap'`, 방위도법): 단위벡터 공간에서 반공간(p · c ≥ cos r) 클리핑, 경계 구간은 원호를 따라 촘촘히.
- 바다 면 = 도메인 외곽선(`compare.js` 의 `domainOutline` 을 공용 모듈로 옮겨 재사용).
- 캔버스 그리기는 `js/ui/exportModal.js` 에서: bbox → 픽셀 변환(y 뒤집기), 땅은 even-odd 채우기.

## 3. 검증 (`tests/suite.js` 15장 「PNG 벡터」)
- 모든 도법 × 정축(가능한 도법은 횡축·사축도)에서: 경로 좌표 모두 유한, 날짜변경선을 건너뛰는 선분(투영 후 길이가 지도 폭의 1/2 초과) 없음.
- 구드: 로브 경계를 걸치는 경로 없음.
- 도메인 밖 좌표 없음(사각·원형 도메인).
- 색 규칙표를 순수 함수(`exportColors({ fill, invert })`)로 두고 6경우 검사.
- 수동: 이 PC Chrome 에서 실제 마우스 더블클릭으로 중심 이동·체크박스·자동 맞춤 복귀 확인, PNG 를 열어 투명 배경·두 색 확인(Equal Earth, 메르카토르, 구드, 평사 사축).
